When It Broke

Two real bugs from this exact app, and the debugging instinct each one teaches.

This actually happened

Everything you're about to see is a real bug that shipped to the live app before it was caught — not a made-up example. Debugging intuition comes from real breakage, so here it is.

Spot the bug

This is (almost) the real code for every popup in the app. Every button inside it — Save, Send, Cancel — stopped working the moment this line shipped. Click the line you think is responsible.

Find the bug:

1function modalConfirmRedeem(reward) {
2 return `<div class="modal" onclick="event.stopPropagation()">
3 <h3>Redeem ${reward.title}?</h3>
4 <button data-action="confirm-redeem" data-reward="${reward.id}">Send request</button>
5 </div>`;
6}

Why this one line broke everything

Remember Module 1's event delegation — one listener on document catches every click in the app by letting it "bubble" up from wherever you clicked. The line onclick="event.stopPropagation()" does exactly what it says: it stops that bubble from ever reaching document.

The button's click still fired. It just never got heard.

⚠️
Common mistake

The line looked defensive, not dangerous — a common instinct is "stop this click from closing the popup underneath it." But event delegation means every button's job depends on that same click reaching document. Stopping it anywhere stops it for everything nested inside.

A second bug: the router that wasn't broken

Scenario

An automated testing tool changed the page's address to a new screen. The screen never updated — it looked exactly like Module 3's router was broken. But real users clicking real links saw it work perfectly every time. What's actually going on?

What both bugs teach

🖱️

Click-test, don't just read

The stopPropagation bug was invisible in the code review — it only showed up the moment someone actually clicked "Save."

🧭

Match the real path

Testing tools can take shortcuts real users never take. If a bug only shows up in one specific tool, suspect the tool before the app.

📡

Caches hide your fixes

A CDN can keep serving an old file for minutes after you've pushed a real fix — confirm with the actual bytes, not just "I pushed it."
