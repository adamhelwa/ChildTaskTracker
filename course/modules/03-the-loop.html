The whiteboard, wiped and redrawn

render() doesn't figure out what changed and tweak just that piece. It throws away the entire screen and rebuilds it from STATE, every single time — like a whiteboard that gets wiped clean and redrawn from memory after every edit, rather than erasing just one word.

💡
Key insight

Frameworks like React exist specifically to avoid this — they compare old and new versions and only touch what changed, called diffing. This app skips that entirely: no framework, no build step, just a template rebuilt from scratch. Slower in theory, invisible in practice at this scale, and radically simpler to reason about.

The notebook that survives closing the tab

  try {
    const raw = localStorage.getItem(STORAGE_KEY);
    return raw ? JSON.parse(raw) : null;
  } catch { return null; }
