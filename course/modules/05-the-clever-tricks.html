The Clever Tricks

Two small pieces of logic that make a 24-hour wait and a forgiving streak both testable in seconds.

The problem with "wait 24 hours"

If a parent doesn't approve a task, it should auto-approve after a day — so a busy evening never costs a kid their streak. But how do you test that without actually waiting a full day, every single time?

The trick: the app never asks the real computer clock what time it is. It keeps its own pretend clock in STATE, and a button in Settings can fast-forward it — like a remote control for time itself.

Fast-forwarding a day

CODE — app.js 
function advanceOneDay() {
  STATE.clock.simulatedNowMs += 86400000;
  STATE.clock.simulatedDate = isoDate(new Date(STATE.clock.simulatedNowMs));
  checkAutoApprovals();
  saveState();
  showToast('⏩ A new day has begun!');
  render();
}
PLAIN ENGLISH

Add exactly one day's worth of milliseconds — 86,400,000 of them — to the pretend clock.

Update the human-readable date to match.

Immediately check: does anything need to auto-approve now that a day has "passed"?

Save, celebrate with a toast, and redraw the screen.

💡
Good to know

Every timestamp in the app — when a task was marked done, when a redemption was requested — is measured against this pretend clock, not the real one. That's what makes the whole demo deterministic and repeatable.

The check that actually approves things

CODE — app.js 
function checkAutoApprovals() {
  let changed = false;
  STATE.completions.filter(c => c.status === 'pending').forEach(c => {
    if (nowMs() - c.markedAtMs >= 86400000) { approveCompletion(c.id, 'auto'); changed = true; }
  });
  if (changed) saveState();
}
PLAIN ENGLISH

Look at every task still waiting on a parent.

For each one: has a full day passed since it was marked done?

If yes, approve it automatically and remember that something changed.

Only bother saving if anything actually got auto-approved.

A streak survives one bad day

Miss a single day and a real streak shouldn't just vanish — that's punishing, and it's how habit apps lose people. This one forgives exactly one missed day before it resets, like a library that waives your fee once but not twice.

CODE — app.js 
let streak = 0, forgiven = false, cursor = addDays(todayStr(), -1), guard = 0;
while (guard++ < 90) {
  const due = tasksForChild(childId).filter(t => isTaskDueOn(t, cursor));
  if (due.length > 0) {
    const allDone = due.every(t => {
      const c = findCompletion(t.id, cursor);
      return c && (c.status === 'approved' || c.status === 'auto_approved');
    });
    if (allDone) streak++;
    else if (!forgiven) forgiven = true;
    else break;
  }
  cursor = addDays(cursor, -1);
}
PLAIN ENGLISH

Start counting from yesterday, with no forgiveness spent yet.

Walk backward day by day, up to 90 days, so this can never run forever.

Only count a day if the kid actually had tasks due on it.

Were every one of those tasks approved?

If yes: the streak grows by one.

If no, and forgiveness hasn't been used yet: spend it, and keep going.

If no, and forgiveness is already spent: stop counting — the streak ends here.

Step one more day into the past and repeat.

A loop walking backward through the calendar, one forgiven flag, one break. That's the entire streak-forgiveness feature.
